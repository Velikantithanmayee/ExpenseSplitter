# ExpenseSplitter

A Java-based application designed to help users manage shared expenses and organize spending among multiple users.

## Features
- Manage user information
- Record and organize expenses
- Categorize expenses
- Store expense and user data locally

## Technologies Used
- Java
- Object-Oriented Programming
- File Handling

## Project Structure
- `src/` — Java source code
- `expenses.txt` — Expense data
- `users.txt` — User data

## How to Run
1. Install the Java Development Kit (JDK).
2. Open the project in VS Code.
3. Compile and run the Java application using the appropriate entry point.

## Purpose
This project demonstrates Java programming, object-oriented design, and basic expense management.
